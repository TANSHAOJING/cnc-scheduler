# CNC排产管理系统

一个专为CNC加工车间设计的生产排产管理工具，支持产品产量安排、人员调配、机台分配、加工数量录入、UPH产能达标计算和计件统计。

## 功能特性

- **账号管理**
  - 默认管理员：谭绍景 / 226178
  - 支持账号注册
  - 管理员可查看所有账号并分配角色（操作工/负责人）

- **基础数据**
  - 导入机台工序表（各机台加工产品工序表.xlsx）
  - 导入产品工时表（各款产品工序工时表.xlsx）
  - 自动匹配机台、产品、工序与UPH

- **排产管理**
  - 按日期、机台、操作工、班次安排生产
  - 根据UPH自动计算建议计划数量

- **加工录入**
  - 操作工按设备录入加工数量
  - 支持多次录入和历史记录查看

- **产能报表**
  - 按日期/班次统计计划 vs 实际
  - 根据UPH计算标准产量，判断是否达标

- **数据同步**
  - 通过 GitHub 同步数据（data.json）
  - 支持手动上传/拉取和自动同步

## 使用说明

1. 用管理员账号登录后，先导入两个基础数据 Excel 文件。
2. 在「排产管理」中为机台安排操作工和生产任务。
3. 操作工在「加工录入」中填写实际完成数量。
4. 在「产能报表」中查看达标情况。
5. 配置 GitHub 同步，实现多设备数据共享。
